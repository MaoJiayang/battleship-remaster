# AI 风险评估模块解耦重构说明

**日期**: 2025-12-13  
**版本**: v1.0  
**状态**: ✅ 已完成

---

## 📋 重构目标

1. **解耦风险评估功能**：将风险评估相关函数从 `aiStrategy.js` 提取到 `aiCore.js`
2. **统一决策逻辑**：让 `SimulationEngine.js`（模拟对局）与 `aiStrategy.js`（实战对局）使用完全相同的决策逻辑
3. **修正配置不一致**：解决参数搜索中 `riskAwareness` 参数存在但未生效的问题

---

## 🔍 问题分析

### 1. 原有架构问题

- **风险评估功能仅存在于 `aiStrategy.js`**
  - `simulateMultiStepThreats()` - 多步威胁推演
  - `calculateRiskBonusUnified()` - 风险加成计算
  - 相关辅助函数（武器范围、船只格子等）

- **`SimulationEngine.js` 未使用风险评估**
  - 代码中有注释："简化版风险计算（不做多步推演，提高速度）"
  - `riskAwareness` 参数被接受但从未使用
  - 导致模拟对局与实战对局行为不一致

- **参数搜索配置与实际不符**
  - `tools/grid-search/run.js` 中定义了 `riskRange` 搜索范围
  - 但由于 `SimulationEngine` 未实现，搜索结果无效
  - 浪费了大量计算资源

### 2. 可行性分析

**结论：完全可行**

关键发现：
- 风险评估依赖**对称推演**（模拟对手攻击）
- 对称推演需要 `opponentViewGrid`（对手视角的我方棋盘）
- **在模拟对局中，双方视角都可用**（`viewGridA` 和 `viewGridB`）
- 因此风险评估可以在模拟对局中完全启用

---

## 🎯 重构方案

### 第一步：提取到 aiCore.js

将以下函数从 `aiStrategy.js` 移至 `aiCore.js`：

```javascript
// 核心风险评估函数
export function simulateMultiStepThreats(opponentViewGrid, myShips, opponentShips, alpha)
export function calculateRiskBonus(action, shipThreats, beliefState, abilities, myShips, alpha)

// 辅助函数（内部使用）
function getWeaponCoverage(weapon, r, c)
function getShipCells(ship)
function accumulateThreat(action, probGrid, abilities, targetShips, threats)
function updateSimulatedState(simViewGrid, action, abilities, probGrid)
function isActionAvailable(action, abilities)
function simulateAbilitiesAfterLoss(ships, lostShip)
```

**设计原则**：
- 保持纯数据逻辑，不依赖 DOM
- 统一使用 `aiCore` 中的 `evaluateAction` 和其他共享函数
- 参数名改为通用（如 `opponentViewGrid` 而非 `playerViewGrid`）

### 第二步：更新 aiStrategy.js

```javascript
// 更新导入
import {
    // ... 现有导入
    simulateMultiStepThreats,
    calculateRiskBonus  // 重命名为更简洁的名称
} from './aiCore.js';

// 删除重复的函数定义
// 删除武器实例创建代码（已在 aiCore 中）
// 删除常量定义（已在 aiCore 中）

// 保持调用代码不变
if (riskAwareness > 0 && playerViewGrid) {
    shipThreats = simulateMultiStepThreats(
        playerViewGrid, 
        enemyShips, 
        myShips, 
        alpha
    );
}

const normRiskBonus = calculateRiskBonus(
    action, shipThreats, beliefState, abilities, enemyShips, alpha
);
```

### 第三步：启用 SimulationEngine 风险评估

```javascript
// 更新导入
import {
    // ... 现有导入
    simulateMultiStepThreats,
    calculateRiskBonus
} from './aiCore.js';

// 在 _executeTurn 中添加风险评估
_executeTurn(config, myShips, enemyShips, enemyGrid, viewGrid, damageGrid, side) {
    // ... 现有代码
    
    // 【新增】获取对手视角并进行风险评估
    let shipThreats = null;
    if (config.riskAwareness > 0) {
        const opponentViewGrid = side === 'A' ? this.viewGridB : this.viewGridA;
        shipThreats = simulateMultiStepThreats(
            opponentViewGrid,
            myShips,
            enemyShips,
            config.alpha
        );
    }
    
    // 【新增】在行动评估中应用风险加成
    for (const action of actions) {
        const baseUtility = evaluateAction(/*...*/);
        
        let score = baseUtility;
        if (shipThreats && config.riskAwareness > 0) {
            const normRiskBonus = calculateRiskBonus(
                action, shipThreats, beliefState, abilities, myShips, config.alpha
            );
            score = baseUtility * (1 + config.riskAwareness * normRiskBonus);
        }
        
        // ... 选择最优行动
    }
}
```

## ✅ 重构结果

### 代码变更

1. **aiCore.js** - 新增 260+ 行
   - 导出 `simulateMultiStepThreats()`
   - 导出 `calculateRiskBonus()`
   - 新增 6 个内部辅助函数

2. **aiStrategy.js** - 删除 260+ 行
   - 删除重复的风险评估函数
   - 更新导入语句
   - 简化函数调用（删除 `LOOKAHEAD_STEPS` 参数）

3. **SimulationEngine.js** - 新增 30+ 行
   - 更新导入语句
   - 在 `_executeTurn` 中添加风险评估逻辑
   - 与 `aiStrategy.js` 保持完全一致的决策流程

### 功能改进

| 功能 | 重构前 | 重构后 |
|------|--------|--------|
| 风险评估共享 | ❌ 仅 aiStrategy | ✅ aiCore 统一提供 |
| 模拟对局风险评估 | ❌ 未实现 | ✅ 完整实现 |
| 代码重复 | ❌ 大量重复 | ✅ 零重复 |
| 参数搜索有效性 | ❌ risk 参数无效 | ✅ 所有参数有效 |
| 实战/模拟一致性 | ❌ 行为不一致 | ✅ 完全一致 |

### 性能影响

**风险评估开销**：
- 每回合需要 5 步推演
- 每步推演需要 50 次蒙特卡洛采样
- 总计约 250 次采样 + 行动评估

**建议**：
- 低难度/快速测试：`riskAwareness = 0`（禁用）
- 正常对局：`riskAwareness = 0.3-0.6`
- 高级 AI：`riskAwareness = 0.7-0.9`
- 参数搜索时可适当降低采样数

## 🎓 开发指南更新

### 新增 AI 决策时的注意事项

1. **所有 AI 决策逻辑都应在 aiCore.js 中实现**
   - aiStrategy.js：实战对局入口（薄封装）
   - SimulationEngine.js：模拟对局入口（薄封装）
   - aiCore.js：核心逻辑（供两者共享）

2. **风险评估的使用**
   - 需要 `opponentViewGrid`（对手视角）
   - 在实战中需要 game.js 传递 `playerViewGrid`
   - 在模拟中使用 `viewGridA` 或 `viewGridB`
   - 如果不提供，风险评估自动跳过（优雅降级）

3. **参数调优建议**
   - 使用 `tools/grid-search/run.js` 进行网格搜索
   - 所有参数（alpha, risk, randomness）现已完全生效
   - 推荐先搜索 alpha，再搜索 risk
