# AI对战可视化使用说明

## 📖 功能简介

AI对战可视化是海战棋网格搜索工具的扩展功能，用于直观展示两个AI配置之间的单次对战过程。

## 🚀 启动方式

1. 启动网格搜索服务：
   ```bash
   cd tools/grid-search/web
   node server.js
   ```

2. 访问主界面：http://localhost:3000

3. 点击"🎮 AI对战可视化"按钮跳转到可视化页面

## ⚙️ 配置参数

### AI-A 配置（先手/红方）
- **Alpha** (0-1): 信息增益与伤害期望的平衡参数，越高越倾向于探索
- **Risk** (0-1): 风险规避系数，越高越倾向于防守性决策

### AI-B 配置（后手/蓝方）
- **Alpha** (0-1): 同上
- **Risk** (0-1): 同上

### 播放控制
- **回合间隔** (ms): 每回合之间的延迟时间，用于控制播放速度

## 🎮 操作说明

### 开始对战
1. 配置双方AI参数
2. 设置回合间隔（建议 500-1000ms）
3. 点击"▶️ 开始对战"
4. 等待后端模拟完成（通常 1-3 秒）
5. 自动开始逐帧回放

### 播放控制
- **⏸️ 暂停**: 暂停当前回放
- **▶️ 继续**: 继续播放
- **🔄 重置**: 清空网格，返回初始状态

### 查看结果
- 对战结束后会自动弹出结果模态框
- 显示胜者、总回合数、双方配置
- 可关闭模态框继续查看最终战场状态

## 📊 界面说明

### 舰队面板
- **红方（AI-A）**: 左侧面板，先手
- **蓝方（AI-B）**: 右侧面板，后手
- **舰船列表**: 显示5艘舰船状态（🚢 BB, ✈️ CV, ⚓ CL, 🛥️ DD, 🌊 SS）
- **沉没标记**: 被击沉的舰船会变灰并划线

### 战场网格
- **🌊 蓝色**: 未知海域
- **⚪ 白圈**: 未命中
- **💥 爆炸**: 受损
- **☠️ 骷髅**: 该格被毁
- **❓ 问号**: 声纳疑似目标

### 战况日志
- 实时显示双方行动
- 回合分隔线
- 攻击结果（命中/未命中）
- 舰船沉没提示

## 🔧 技术细节

### 后端流程
1. 接收配置参数 → `/api/simulate`
2. 创建 `SimulationEngine` 实例
3. 运行完整对战并收集历史事件
4. 返回事件流给前端

### 前端流程
1. 接收事件流
2. 逐步渲染每个事件：
   - `INIT`: 显示舰船部署
   - `TURN_START`: 更新回合信息
   - `ATTACK`: 更新网格和日志
   - `SHIP_SUNK`: 标记沉没舰船
   - `GAME_END`: 显示结果
3. 根据时延控制播放速度

## 💡 使用建议

### 调试AI参数
- 先在网格搜索中找到优秀配置
- 在可视化中观察具体决策过程
- 分析强弱配置的行为差异

### 对比测试
1. 设置一方为基准配置（如 α=0.7, Risk=0.2）
2. 调整另一方参数观察影响
3. 多次运行取平均表现

### 性能优化
- 回合间隔设置为 0 可快速跳转到结果
- 回合间隔 800-1000ms 适合详细观察
- 暂停后可仔细查看网格状态

## 🐛 已知限制

1. **单次对战**: 每次只能运行一场对战，需要多次对比请使用网格搜索
2. **随机性**: 由于舰船部署和决策随机性，同配置多次运行结果可能不同
3. **无回退**: 不支持后退播放，需要重新运行
4. **内存限制**: 对战历史全部加载到内存，超长对战（>100回合）可能较慢
